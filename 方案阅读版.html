Xiaohongshu AI Workflow

面向知识科普账号的 AI 辅助内容工作流，覆盖选题审核、文案生成、图片制作、素材管理和发布前填写。人工负责选题审核、最终审核与提交发布。

仓库包含工作流文档、生图规范和独立的 Python 内容包示例。

工具组成

工具 职责
飞书多维表格 保存选题、资料来源、人工审核结论和计划时间
Codex 读取项目规则与选题，运行本地脚本，调用生成工具，整理文件，操作浏览器
Antigravity CLI 由脚本调用，完成选题研究、标题、正文、标签及逐页制图说明
GPT 生图工具 通过 Codex 内置 image_gen 生成封面、内容页和尾图
Easel 本地内容管理网页，提供文案、图片预览和日历排期视图
Chrome＋浏览器控制扩展 连接 Codex 与已登录的创作者中心，用于上传素材和填写发布页面

工作流程

阶段 处理步骤 输出
1. 选题审核 人工审核飞书条目和计划时间，Codex 读取通过的条目 已审核选题、资料和时间
2. 文案生成 Codex 通过项目脚本调用 Antigravity 发布文案、逐页文字和画面要求
3. 图片制作 Codex 将制图说明、参考图和生图规范交给 GPT，逐页生成并检查 封面及内容页，每页一个图片文件
4. 素材整理 Codex 核对图文对应关系、数量和顺序，按日期归档；Easel 展示结果 文案、有序图片和计划时间
5. 发布前填写 Codex 控制 Chrome 上传素材，填写文案、话题、声明和时间，读回比较 待人工审核、未提交的编辑页面
6. 人工发布 人工检查内容与设置，提交发布或定时发布 平台确认的发布结果

填入定时时间不等于平台已接受定时任务；状态在人工提交、平台确认后更新。

规则文件

快速开始

运行环境：Python 3.10 或更新版本，无第三方 Python 依赖。在仓库根目录运行：

python examples/prepare.py examples/sample.json

默认输入未提供图片，人工审核字段也为 false，因此返回 ok: false 和退出码 2。替换素材和审核记录后，可生成待人工审核的本地内容包，详见示例说明。

该命令只运行本地示例，不会连接模型、飞书或小红书。完整工作流所需的服务适配器、生产脚本和账号配置不包含在仓库中。

工作流程

工具职责和总流程图见项目首页。以下说明各阶段的输入、操作和输出。

1. 选题审核

飞书多维表格保存题目、资料来源、审核结论和计划时间。人工检查题材与资料，将可制作的条目标记为“通过”。

Codex 通过本地脚本读取当前审核结果。未通过的条目不进入制作；已有图片或处于人工处理中的内容保留，不重复生成。

输出：已审核选题、资料、发布日期和时刻。

2. 文案生成

Codex 调用 Antigravity CLI 完成资料研究和写稿。CLI 提供命令行入口，可由脚本启动。

文案分为两部分：

  • 发布文案：小红书使用的标题、正文和标签。
  • 逐页制图说明：各页文字、页面角色、画面要求和参考图用途。

多语言内容按语言分页，详细文字保存在同一份制图说明中。研究来源和未确定的问题单独保留，不混入发布正文。生成结果需要检查必填字段与内容，缺项条目单独处理。

输出：本地发布文案，以及供生图使用的逐页说明。

3. 图片制作

Codex 通过内置 image_gen 传入制图说明、规范和参考图，将生成结果保存到本地。

先制作封面，检查实物、文字和版式，再使用封面作为参考制作后续页面，保持物体和视觉风格一致。

“封面＋四种语言各一页＋尾图”对应六张独立图片。逐页检查术语、日期、编号和物件结构，错误页修正后重新检查。

输出：数量齐全、顺序明确的图片文件。

4. 素材整理

Codex 根据图片内容和编号匹配文案，检查页数及顺序，将素材按日期、篇目归档。目录结构示意：

日期/
  篇目/
    发布包.txt          标题、正文、标签
    制图说明.txt        每页文字和画面要求
    images/
      01_封面.png
      02_内容页.png
      ...

“制图说明.txt”是通用名称，多语言流程使用“多语言发布包.txt”。平台正文读取“发布包.txt”，不使用整份制图说明。

Easel 提供内容预览、复制和排期视图；本地脚本负责文件整理。

输出：本篇发布文案、有序图片列表和计划时间。

5. 发布前填写

Chrome 通过浏览器控制扩展连接 Codex。账号由人工登录并确认，浏览器工具在已登录的创作者中心内操作。

按素材清单上传图片，填写标题、正文、正式话题、内容声明和日期时刻。完成后读取页面字段，与本地内容比较。

浏览器操作采用 Chrome 扩展控制方式，不依赖第三方小红书 MCP 的发布接口。

输出：已填写、未提交的编辑页面。自动化不点击最终发布按钮。

6. 人工审核与发布

人工检查图片顺序、文案事实、话题、原创与 AI 声明、发布时间。发现问题时返回对应阶段修正。

最终由人工提交发布或定时发布，平台确认后再登记状态。生成文件、填好页面、平台接受发布分别记录，不互相替代。

定时维护

定时任务调用本地脚本读取审核结果、补充缺失文案、记录失败并保护已有内容。生图与浏览器填写可按批次交给 Codex 执行。

审核表不可读、文案缺字段、素材错配等情况应停止受影响条目并报告，保留其他已完成内容。人工审核和最终提交始终保留。

上手指南

本指南说明如何完成一篇内容，并逐步连接文件整理和浏览器工具。完整工作流的服务适配器不包含在仓库中；可直接运行的部分为本地内容包示例。

1. 创建选题表

在飞书多维表格中建立四列：题目、资料来源、审核结论、计划时间。补充题目和资料，人工核对后将审核结论改为“通过”。

未配置飞书读取接口时，可将已审核条目复制给 AI 工具，先验证内容制作流程。

2. 生成发布文案与制图说明

工作流使用 Antigravity CLI 生成文案。也可先在可用的 AI 工具中使用以下模板：

制作一篇知识科普小红书内容。
选题：[题目]
已审核资料：[资料]

输出两部分：
1. 发布文案：标题、正文、标签。
2. 制图说明：逐页列出图中文字和画面要求。

不确定的事实单独列出，等待人工审核。

检查内容后，将发布文案保存为“发布包.txt”，逐页说明另存。研究备注不放进发布正文。

3. 生成图片

将逐页说明、参考照片和生图规范传给图像工具。

  • Codex 内置生图：逐页调用图像工具并保存结果。
  • ChatGPT 网页：上传说明和参考图，生成后下载图片。

先检查封面，再将封面作为其他页的参考。每页保存为独立图片，按顺序命名。检查实物结构、文字完整性和全套一致性。

4. 整理内容包

为每篇内容创建独立文件夹，存放发布包、制图说明和 images 目录。可向 Codex 提供以下任务：

检查该文件夹中的发布文案与图片是否对应。
核对图片内容、页数、顺序以及封面日期和编号。
列出缺项和错误。保留原文件，不覆盖人工修改。

Easel 提供内容库和日历视图；未接入 Easel 时，可直接检查本地文件夹。

5. 准备发布页面

人工登录小红书创作者中心，确认账号。首次使用时，先手工上传一篇，核对素材、标题、正文、话题、声明和时间。

Codex 已连接 Chrome 浏览器工具后，可将重复填写交给浏览器控制：

根据该文件夹准备一篇小红书编辑页面。
核对已登录账号，按顺序上传素材，填写标题、正文、
正式话题、必要声明和计划时间。
完成后逐项读回比较，保留页面供人工审核。
不要点击发布或定时发布按钮。

Chrome 安装与浏览器工具连接是两个步骤，需要在使用的工具中单独完成连接。最终审核和提交由人工完成。

6. 配置定时维护

单次执行稳定后，再设置重复运行时间。本地脚本读取审核结果、补充缺项、记录失败，保留已有图片和人工修改；定时任务不提交发布。

运行本地示例

需要 Python 3.10 或更新版本。在仓库根目录运行：

python examples/prepare.py examples/sample.json

默认输入缺少图片，审核字段为 false，因此预期返回 ok: false 和退出码 2。替换输入后，可执行校验和组包，详见示例说明。

示例不调用模型、飞书或浏览器，不包含自动发布功能。

图像生成规范

适用于生活物件类知识图卡。将规范随制图说明传入图像工具；支持 Skills 的环境可将其组织为可复用的任务说明。

1. 定义实物结构

提供实物参考图，并明确以下信息：

  • 所属完整物件与安装位置。
  • 连接对象、部件数量和使用状态。
  • 不可改变的孔、槽、边缘、折弯和比例。
  • 材料、颜色与关键尺寸关系。

常见错误是将连接两个物体的零件画成单个物体上的附片。应按参考图修正连接关系，而不是仅调整画面精细度。

2. 区分结构参考与风格参考

参考图 A 定义实物结构，参考图 B 定义光线、背景和版式。

保留真实结构，允许调整摄影环境。不得为美化画面增加不存在的按钮、孔洞或装饰。

3. 保持系列一致性

先生成并检查封面，再生成第一张内容页。后续页面以封面固定物体身份，以第一张内容页固定版式。

全套保留相同颜色、材质、轮廓和关键结构。可调整裁切，不替换产品型号或移动目标部件。

4. 明确页面清单

四语言套图的示例结构为：封面、中文页、日语页、英语页、第四语言页、尾图，共六张独立图片。

按页面清单逐张生成和保存，不以拼图或重复裁切代替独立页面。单图内容按实际需求制作，不套用六页要求。

5. 检查文字与编号

术语、读音和例句在文案阶段核对。生图时不新增未经审核的标准、专利、年份或数字。

日期和编号使用明确值。生成后打开原图校对，再以手机显示尺寸检查可读性。文字过密时删减内容或增加分页，不持续缩小字号。

制作说明模板

替换方括号内的内容后使用：

制作一张知识科普图片，只生成本页。

本页用途：[封面/内容页/尾图]
画幅：[例如竖版 3:4]
准确文字：[已经核对的文字]
日期和编号：[如需要，填确切值]

参考图 A：保留实物结构、位置、数量和比例。
参考图 B：参考背景、光线和文字排版。
不可改动：[关键结构]
允许调整：[背景、光线、裁切等]

后续页面沿用已通过封面的同一物体，不换型号和颜色。
不新增未经确认的知识、品牌或结构。
文字放不下时报告，不使用过小字号。

返工应指定错误及保留项，例如：“保留版式，按参考图修正目标部件的连接方式。”未受影响的页面保留。

本地内容包示例

使用 Python 标准库检查输入清单和本地图片，生成待人工审核的内容包。不联网、不登录、不调用模型，不包含发布功能。

功能

  • 校验标题、正文、标签、完整日期时间和页面角色。
  • 检查显式人工审核字段及 PNG/JPEG/WebP 文件头。
  • 计算 SHA-256，按清单顺序复制图片。
  • 生成发布包和素材清单，始终记录 submitted: false。
  • 拒绝覆盖已有输出目录。

文件头检查不包含完整图片解码或视觉识别。事实、图中文字、物体结构、日期和编号需要人工检查，审核字段应反映实际检查结果。

环境要求

Python 3.10 或更新版本，无第三方依赖。以下命令在仓库根目录执行；Windows 也可使用 py -3 代替 python。

校验默认输入

python examples/prepare.py examples/sample.json

默认输入缺少图片，审核字段为 false，预期返回 ok: false 和退出码 2。

使用自定义输入

  1. 复制 examples/sample.json 为 examples/my-note.json。
  2. 在 examples/assets 放入图片，更新清单中的相对路径。
  3. 填写编号、标题、正文、标签和完整计划时间。
  4. expected_roles 与 media 中的角色和顺序保持一致。
  5. 人工检查事实、图片与封面信息后，将相应审核字段设为 true。
  6. 运行校验；需要组包时指定输出目录。
python examples/prepare.py examples/my-note.json
python examples/prepare.py examples/my-note.json --out examples/practice-output

输出目录必须不存在。组包成功只表示本地资料准备完成，后续仍需人工审核与平台提交。

输出结构

practice-output/
  发布包.txt
  images/
  manifest.json

manifest.json 记录编号、计划时间、图片角色、来源相对路径、输出路径、SHA-256 和未提交状态：

production_status: PACKAGE_READY
review_status: PENDING_FINAL_HUMAN_REVIEW
platform_status: NOT_SUBMITTED
submitted: false

示例未集成飞书、文案生成、生图、Easel 或浏览器接口。完整工作流见上手指南。
